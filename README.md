# Moment Stopwatch

모네의 수련 작품을 배경으로 한 스탑워치 웹페이지입니다.

## 주요 기능

- 시작, 일시정지, 이어서 측정, 랩 추가와 완주 기록
- 현재 구간 시간과 1/100초 단위의 누적·구간 기록
- 야외 고대비 모드와 수련 물결 애니메이션
- 브라우저에 기록 저장 및 여러 탭 사이 기록 동기화

## 실행하기

`index.html`, `style.css`, `app.js`를 같은 폴더에 둔 뒤 `index.html`을 브라우저에서 엽니다. 웹 서버를 사용하는 경우 정적 파일로 그대로 올리면 됩니다. 기록과 설정은 사용하는 브라우저에 저장됩니다.

배경 이미지는 인터넷에서 불러옵니다. 수동 측정이므로 표시 단위와 실제 계측 정확도는 다를 수 있습니다.
